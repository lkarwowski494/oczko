# Szablon: odczyt zasad grupy i dziennik wpisów (rola 11, WZ1, KO-217; P-1029, P-1030)

**Pusty szablon w publicznym repo — nie wpisuj tu nazw grup, adresów grup ani danych osób.** Wypełnioną kopię (z nazwami) trzymaj w `oczko-warsztat/11-wzrost/2026-11-24-fb/grupy.md` (prywatne); w publicznym `docs/wzrost/dziennik.md` trafia tylko podsumowanie tygodnia (tabela 4, same liczby). Szkice i teksty: `docs/wzrost/szkice-facebook.md`, `docs/wzrost/pakiet-startowy.md`. Wypełnia właściciel; agent niczego nie publikuje i do grup nie dołącza (zasada wspólna 12).

## 1. Szablon odczytu grupy (ok. 5 min na grupę; P-1029 pkt 2)
Zakładka „Informacje” i przypięte posty. Jeden wiersz na grupę. **Grupa bez wypełnionego wiersza nie dostaje wpisu.**

| # | Nazwa grupy | Adres | Język | Typ (ogólna dziewiarska / szydełkowa / początkujący / inne) | Członkowie (liczba) | Daty 2–3 ostatnich wpisów | Wpisy zatwierdza administrator? (tak/nie) | Zasada o promocji / linkach / reklamie — cytat dosłowny albo „brak zasad” | Osobny wątek promocyjny? | Data odczytu | Decyzja (wpis / tylko w wątku / skreślona) |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | | | | |
| 2 | | | | | | | | | | | |

Reguły decyzji (z P-1029):
- zasada zakazuje promocji, linków albo reklamy → **skreślona**;
- jest osobny wątek promocyjny → tylko w tym wątku albo wcale;
- „brak zasad” → wpis dozwolony; nadal jawnie jako autor, każdy wpis inny;
- wpis zatwierdza administrator → po zatwierdzeniu wpis liczy się tak samo; odrzucenie = grupa skreślona.

## 3. Liczniki i stop (P-1029 pkt 6, P-1030)
- Usunięcia wpisów: ___ (2 = **stop**) · ostrzeżenia Facebooka: ___ (jakiekolwiek = **stop**).
- Po stopie: żadnego kolejnego wpisu; zgłoszenie do koordynatora z wierszami z dziennika; powrót do opcji „najpierw pytanie do administratora” (P-1029 (a)).
- Grupa, w której wpis usunięto: skreślona, bez ponawiania.
