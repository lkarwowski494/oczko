A „Dzianina”

Idea: karta projektu to kawałek dzianiny, który przyrasta rząd po rzędzie do celu części.

Element firmowy: wysokość dzianiny = rzędy gotowe / cel części; jaśniejszy pas = rzędy dziś; igła = bieżący rząd; przerywana linia = cel; ząbek w brzegu = następne przypomnienie. VoiceOver: „Rękaw lewy: 42 z 96 rzędów, dziś 14 rzędów, następne ujmowanie w rzędzie 47”.
